System 1 vs System 2 — give me one example, from the book, of System 1 making a snap judgment that System 2 would override on reflection.

When I see a friendly face I instantly assume someone is trustworthy — that's System 1 doing a fast, automatic read on warmth. System 2 would override that by asking whether the person has actually behaved trustworthily before, weighing evidence rather than the impression. Kahneman's halo-effect and cognitive-ease arguments cover this — System 1 substitutes the easier question ("do they look nice?") for the harder one.
